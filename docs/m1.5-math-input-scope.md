## 1. 文档职责

本文是 M1.5 首期数学图形与输入边界的正式范围基线，冻结：

1. 支持的数学图形；
2. 接受的方程类别和等价形式；
3. 明确拒绝的相邻能力；
4. M1 与 M1.5 的路由边界；
5. 阶段 13–15 不得突破的产品范围。

本文不替代：

* `数学绘图助手 PRD.md` 的产品与验收要求；
* `docs/architecture.md` 的模型、线程和依赖方向；
* `docs/supported-formulas.md` 的现有 M1 语法、安全 limits 和错误契约；
* 阶段 13 的真实接口与 typed Spec 设计；
* 阶段 14 的参数化采样、视口、残差和资源原型；
* 阶段 15 的教材样例、GUI、性能和 M1.5 验收。

若上述文档与本文出现冲突，必须先修正文档并重新审核，不得由实现自行选择。

## 2. 产品、用户与教材策略

M1.5 首期面向全国中性口径的高中数学教师：

* 不绑定省份；
* 不绑定教材版本；
* 不绑定教材章节编号；
* 不绑定考试卷型；
* 不新增高考专项、竞赛或其他备考专属能力；
* 使用跨教材可理解的全国中性数学术语。

该选择关闭 P1-01 和 P1-02 的阶段 13 入口事项，但不代表已经完成 P0-07 的真实教材表达式验收。P0-07 仍由阶段 15 关闭。

M1.5 只扩展单个一般直线、圆和受限圆锥曲线方程的识别、分类、采样、绘图、预览和复制，不改变已经通过 M1 checkpoint 的单自变量显函数能力。

## 3. 首期图形范围

M1.5 首期支持：

* 一般非退化直线，包括竖直、水平和斜直线；
* 圆；
* 坐标轴平行、允许平移的非退化椭圆；
* 坐标轴平行、允许平移的非退化双曲线；
* 坐标轴平行、允许平移的非退化抛物线。

圆保持独立产品类型和独立 `CircleSpec`，不并入普通椭圆。

M1.5 新增的正式 PlotKind 为：

```text
LINE_EQUATION
CONIC_EQUATION
```

对应 typed Spec 为：

```text
LineSpec
CircleSpec
EllipseSpec
HyperbolaSpec
ParabolaSpec
```

不得使用一个通用 Spec 加大量可空字段模拟这些类型分支。

## 4. 单个输入的基本形式

每个 M1.5 输入必须：

1. 恰好包含一个等号；
2. 等号左右两侧均非空；
3. 只表示一条完整的待绘制直线、圆或圆锥曲线；
4. 自由变量只能来自 `x`、`y` 的子集；
5. 至少包含 `x`、`y` 中的一个变量；
6. 不要求 `x`、`y` 必须同时出现。

变量范围上可能合法的示例：

```text
x=2
y=-3
x+y=1
x^2+y^2=25
```

下列形式不属于 M1.5 单方程输入：

```text
x+y=1; x-y=2
x=cos(t), y=sin(t)
x^2+y^2<25
```

没有等号的表达式不自动补写为 `=0`。

## 5. 精确系数范围

M1.5 的一次或二次多项式系数只接受能够精确归一化为有理数的数值，且首期仅包括：

* 整数；
* 有限小数；
* 由合法数字字面量组成的数值分数；
* 在现有复杂度 limits 内，由上述数值进行有限 `+ - * /` 运算得到的精确有理数。

示例：

```text
2
-3
0.5
-1.25
1/2
-3/4
2.5/5
```

分类前必须进行精确处理，不得先转换为普通二进制浮点数，也不得用浮点容差判断系数是否为零。

下列内容不得作为 M1.5 系数：

```text
pi
E
sqrt(2)
sin(1)
log(2,10)
1e-3
a
b
p
r
h
k
```

因此下列输入拒绝：

```text
x^2+y^2=pi
(x-pi)^2+y^2=4
y^2=4*p*x
x^2/a^2+y^2/b^2=1
```

“方程整体乘非零数值”在本文中始终指：整体乘任意能够精确归一化为有理数的非零数值。它不允许用 `pi`、`E`、根式或函数值绕过系数白名单。

纯数字字面量的幂不属于首期系数运算白名单。下列教材风格写法首期拒绝，用户应先把纯数字幂计算为普通整数或分数：

```text
x^2/3^2+y^2/2^2=1
```

其等价的 `x^2/9+y^2/4=1` 属于正式支持范围。该拒绝不影响 `(x-2)^2` 等变量多项式的二次幂形式。

零分母始终拒绝。

## 6. 现有隐式乘法契约

M1.5 继承 `docs/supported-formulas.md` 已冻结的隐式乘法白名单，不新增第二套规则。

接受：

```text
2x
2(x+1)
(x+1)(x-1)
```

因此下列 M1.5 输入可进入后续分类：

```text
2x-y+3=0
2(x+1)=3(y-2)
```

现有 parser 明确拒绝的相邻形式继续拒绝，包括：

```text
x2
x(x+1)
(x+1)x
2sin(x)
2pi
xy
```

需要表达旋转项时，测试和文档使用显式 `x*y`。M1.5 不得为了曲线分类扩大共享 tokenizer 或 parser 的隐式乘法语言。

## 7. 安全门禁

方程必须先通过既有的字符、token、数字位数、AST 节点、嵌套深度、指数、函数参数和完整消费限制，之后才允许进入 M1.5 多项式归一化与系数提取。

原始文本和未经验证的 AST 不得直接传入：

```text
eval
exec
无约束 sympify
通用 parse_expr
通用 solve
无约束 expand
无约束 simplify
无约束 factor
```

不得为了识别直线或圆锥曲线绕过现有安全解析管线，也不得把 M1.5 的有理系数限制扩张为 M1 显函数的全局限制。

## 8. 有界精确归一化

安全门禁通过后，只允许执行保持原方程解集且有明确复杂度上限的精确处理：

1. 将等号两侧归并为同一侧；
2. 有限展开括号；
3. 展开不会形成总次数超过 2 的二次幂；
4. 精确计算纯有理数的 `+ - * /`；
5. 将有限小数精确转换为有理数；
6. 合并同类项；
7. 消除系数精确为零的项；
8. 约去所有项共有的非零有理数因子；
9. 统一方程整体符号；
10. 提取一次或二次多项式的精确系数。

允许：

```text
2*(x+1)=3*(y-2)
(x-1)^2+(y+2)^2=9
(x+y)^2+(x-y)^2=4
```

最后一例展开并合并后 `x*y` 项精确抵消，最终 `B=0`，可以分类为圆。

### 8.1 次数硬边界

变量相关的幂和乘法只能形成总次数不超过 2 的受限多项式。任何结构只要会形成三次或更高次单项式，就直接拒绝，不因后续可能精确抵消而重新接受。

因此下列输入全部拒绝：

```text
x^3+y^2=1
x^2*y=1
x^4+y^4=1
x^3-x^3+x^2+y^2=1
```

这条规则与 PRD 的“幂只允许形成总次数不超过 2 的多项式”和阶段 13 的“三次方程拒绝”保持一致。

### 8.2 禁止的代数变换

M1.5 不得通过以下方式取得支持结果：

* 通用求解；
* 无约束展开、化简或因式分解；
* 约去变量分母；
* 消去可能改变定义域的因子；
* 开平方后猜测正负分支；
* 对三角、指数、对数或根式表达式使用恒等变换；
* 旋转坐标轴；
* 用数值近似把非零系数判为零；
* 把退化二次方程降级为一般直线。

例如 `(x^2-1)/(x-1)=x+1` 必须拒绝，因为约分会改变 `x=1` 处的定义域。

## 9. 统一多项式形式

通过安全门禁和有界精确归一化后，候选必须精确表示为：

```text
A*x^2 + B*x*y + C*y^2 + D*x + E*y + F = 0
```

其中六个系数均为精确有理数，最终总次数必须为 1 或 2。

如果所有变量项消失，则拒绝：

```text
0=0
1=0
```

前者表示整个平面，后者表示空集。

## 10. M1 与 M1.5 路由

统一路由为：

```text
输入
→ 共享 normalizer/tokenizer/parser 和安全门禁
→ 检查既有 M1 直接显函数契约
   → 合法：EXPLICIT_FUNCTION
   → 不是直接显函数候选：继续尝试 M1.5
→ 尝试 LINE_EQUATION 或 CONIC_EQUATION
```

必须区分“不是 M1 直接显函数候选”和“输入结构非法、超限或不安全”。前者可以继续尝试 M1.5，后者必须立即拒绝。

等号一侧恰为单独 `y`、另一侧再次包含 `y` 的结构不是合法 M1 显函数，但在阶段 13 的统一路由中属于可继续尝试 M1.5 的安全单等式。若其能够通过 M1.5 有界精确归一化并形成受支持的一次或二次图形，则返回对应 `LINE_EQUATION` 或 `CONIC_EQUATION`；不得仅因现有 M1 专用 classifier 产生 `explicit_function_y_not_allowed` 就终止统一路由。

例如：

```text
y=x+y             → LINE_EQUATION，LineSpec(x=0)
x+y=y             → LINE_EQUATION，LineSpec(x=0)
2*y=x+2*y         → LINE_EQUATION，LineSpec(x=0)
y=y               → 归一化为零方程，拒绝
```

现有 M1 专用入口、`analyze_explicit_function`、显函数 classifier/validator 及其错误码测试保持不变。上述升级只发生在阶段 13 新增的统一 M1/M1.5 路由中；若调用者明确请求 M1 显函数验证，`y=x+y` 仍返回既有 `explicit_function_y_not_allowed`。阶段 13 必须为这两个入口分别建立行为测试，不得通过修改旧 validator 实现 fallback。

以下输入继续保持 M1 `EXPLICIT_FUNCTION`：

```text
y=-3
y=x^2
x^2=y
y=2*x+1
2*x+1=y
y=sin(x)
y=pi*x
```

它们在几何上可能是直线或抛物线，但不得因此改写已经验收的 M1 PlotKind 或 validated receipt。

以下输入进入 M1.5 分类：

```text
x=2
x+y=1
y+1=x+2
x^2=8*y
y^2=8*x
x^2+y^2=25
x^2/9+y^2/4=1
x^2/9-y^2/4=1
```

`y=sqrt(25-x^2)` 仍是 M1 显函数，只表示上半圆；`x^2+y^2=25` 是 M1.5 圆，表示完整圆。

## 11. 一般非退化直线

最终总次数为 1 时：

```text
D*x + E*y + F = 0
```

要求 `(D,E) != (0,0)`，形成 `LINE_EQUATION` 和 `LineSpec`。

M1.5 LineSpec 正向示例：

```text
x=2
x+y=1
2*x-y+3=0
y+1=x+2
3*x+2*y=6
x/2+y/3=1
2*(x+1)=3*(y-2)
```

下列形式应得到同一条规范化直线：

```text
2*x-y+3=0
0=2*x-y+3
4*x-2*y+6=0
-2*x+y-3=0
```

`y=-3`、`y=2*x+1` 和 `2*x+1=y` 虽然也表示直线，但继续由既有 M1 `EXPLICIT_FUNCTION` 路由处理，不形成新的 `LineSpec`。

## 12. 圆与圆锥曲线

二次候选必须满足 `B=0`、非退化且存在实数图形，并精确分类为以下类型之一。

### 12.1 圆

支持圆心在原点或有理数平移位置、半径大于零的圆。半径平方为正有理数；半径本身不要求是有理数。

```text
x^2+y^2=25
x²+y²=25
(x-2)^2+(y+1)^2=9
25=x^2+y^2
4*x^2+4*y^2=100
x^2+y^2-4*x+2*y-4=0
```

`x^2+y^2=0` 退化为点，`x^2+y^2=-1` 无实点，均拒绝。

### 12.2 椭圆

支持轴与坐标轴平行、允许平移、非退化且有实点的椭圆：

```text
x^2/9+y^2/4=1
x^2/4+y^2/9=1
(x-1)^2/9+(y+2)^2/4=1
4*x^2+9*y^2=36
1=x^2/9+y^2/4
-4*x^2-9*y^2=-36
```

两个半轴相等时分类为圆。只得到一个点或没有实点时拒绝。

### 12.3 双曲线

支持轴与坐标轴平行、允许平移、非退化、左右或上下开口的双曲线：

```text
x^2/9-y^2/4=1
y^2/4-x^2/9=1
(x-1)^2/9-(y+2)^2/4=1
(y-3)^2/16-(x+1)^2/9=1
4*x^2-9*y^2=36
```

`x^2-y^2=0` 退化为两条直线，拒绝。`x*y=1` 的最终 `B!=0`，属于旋转双曲线，首期拒绝。

### 12.4 抛物线

支持轴与坐标轴平行、允许平移、非退化、四个开口方向的抛物线：

```text
x^2=4*y
x^2=-4*y
y^2=4*x
y^2=-4*x
(x-2)^2=8*(y+1)
(y-1)^2=4*(x+2)
x^2-4*x-8*y-4=0
y^2+2*y+4*x-11=0
```

`x^2=0`、`x^2=4` 和 `x^2+1=0` 分别退化或无实点，均拒绝。

## 13. 旋转、退化与无实点判定

旋转项根据最终精确系数 `B` 判断，不根据原始文本是否出现 `x*y` 判断。

```text
(x+y)^2+(x-y)^2=4
```

最终 `B=0`，可接受为圆。

```text
x*y=1
x^2+2*x*y+2*y^2=1
(x+y)^2/9+(x-y)^2/4=1
```

最终 `B!=0`，首期拒绝；不得通过坐标旋转取得支持结果。

所有退化为点、一条或两条直线、空集、整个平面或其他非目标集合的二次方程均拒绝。退化二次方程不得重新分类为一般直线。

没有实数图形的方程必须返回结构化失败，不得生成空白图片并标记成功。

## 14. 变量分母和非多项式隐式方程

变量出现在任何分母中时直接拒绝，即使约分后可能得到一次或二次多项式：

```text
1/x+1/y=1
x/(y+1)=2
(x^2-1)/(x-1)=2
```

非多项式隐式方程首期拒绝：

```text
sin(x)+y=0
abs(x)+abs(y)=1
sqrt(x)+y=2
2^x+y=0
log(x,10)+y=1
```

变量的负整数幂也直接拒绝，因为它形成变量倒数结构，不能进入一次/二次多项式系数提取：

```text
x^-1+y=2
```

其最终错误码和用户文案由阶段 13 在现有错误注册表内确定；本文只冻结其拒绝结果。

## 15. 其他明确拒绝范围

M1.5 首期不支持：

* 多等号；
* 方程组或单输入多公式；
* 不等式；
* 参数方程；
* `x`、`y` 以外的未知变量；
* 未赋值参数；
* 复数系数或复平面图形；
* 科学计数法系数；
* 任意一般隐式曲线；
* 线段、射线、圆弧、半圆或其他局部曲线；
* 区间条件或区域填充；
* 单输入多图叠加；
* 自动求交、相切判断或方程组求解；
* 焦点、准线、顶点、离心率、渐近线等教学标注；
* 参数滑块或实时联动。

每个输入始终表示完整图形。视口裁切只影响显示范围，不改变数学对象。

教学标注仅保留为 M5 候选能力，必须另有需求、设计和验收标准；它不是 M1.5 承诺。

多图叠加属于 M1.6，每个图形必须使用独立输入项，M1.5 不提前改变当前单项场景的原子语义。

## 16. M1 不回归边界

M1.5 不得修改或收窄现有 M1 专用入口的：

* normalizer、tokenizer 和 Restricted AST 基础契约；
* `ConstantNode`；
* 显函数 validator 和 `ValidatedExplicitExpression`；
* `pi`、`E`、函数、指数、对数和隐式乘法契约；
* Scene、RenderActor、状态、预览和复制契约。

至少持续保留：

```text
y=x
y=x^2
x^2=y
y=sin(x)
y=1/x
y=sqrt(x)
y=ln(x)
y=lg(x)
y=log(x,10)
y=2^x
y=exp(x)
y=abs(x)
y=pi
y=pi*x
y=sin(pi*x)
y=E
y=E*x
```

对照规则：

```text
y=pi*x                 → 保持 M1 EXPLICIT_FUNCTION
x^2+y^2=pi             → M1.5 非有理系数，拒绝
(x-pi)^2+y^2=4         → M1.5 非有理平移量，拒绝
x^2+y^2=4              → M1.5 CircleSpec
y+1=x+2                → M1 阶段拒绝；M1.5 LINE_EQUATION
```

阶段 13 不得通过改变既有 M1 分类结果来简化新分类器。

这里的“M1 分类结果”指现有 M1 专用入口和 validated receipt。阶段 13 新增统一路由后，本文明确列出的合法一般直线或圆锥曲线可以从 M1 阶段性拒绝升级为 M1.5 成功；这种升级必须发生在新路由中，并由单独测试证明旧 M1 专用入口未被改写。

## 17. 阶段 13–15 边界

本文只冻结产品和输入范围，不提前冻结具体实现。

阶段 13 负责：

* 真实接口盘点；
* `LINE_EQUATION`、`CONIC_EQUATION` 路由；
* 精确一次/二次系数提取；
* typed Spec 字段和构造不变量；
* 分类、退化和拒绝测试；
* M1 回归。

阶段 14 负责：

* 直线与视口求交；
* 圆和圆锥曲线参数化采样；
* 可见参数区间；
* 自动视口信息消费；
* 一般直线（包括竖直直线）的自动 x/y 范围和默认坐标比例规则；
* 残差容差、采样点、分支和资源原型；
* P0-06 关闭。

阶段 15 负责：

## 18. 变更控制

本范围提交后作为阶段 13 的冻结输入。任何扩大或收窄范围的修改必须：

1. 说明产品和教学理由；
2. 同步 PRD、architecture、decisions、supported-formulas 和联网确认中的受影响内容；
3. 明确对 M1 回归、阶段 14 原型和阶段 15 验收的影响；
4. 由项目所有者批准；
5. 重新进行独立审核后再实施。

未完成上述流程时，阶段 13–15 实现不得自行改变本范围。
