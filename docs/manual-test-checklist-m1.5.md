## 1. 目的与适用边界

本清单用于 Stage 15-G 对 M1 与单项 M1.5 正式 production 应用进行人工 GUI 验收。适用候选的 commit、安装包或启动命令必须由 Stage 15-G 执行人在开始时填写；不得默认使用本文件建立时的工作树。

Stage 15-D3 只建立清单并提供自动化布局/缩放证据。本文件没有执行真实人工验收，没有填写 PASS，没有形成设备、Windows 缩放、logical DPI、device pixel ratio、多显示器、触控或目标软件兼容结论。D3 自动化与开发者基本观察均不得替代下列人工项目。

## 2. 执行前置条件与证据规则

- 仅由项目所有者或获明确授权的 Stage 15-G 人工执行者填写观察结果。
- 每个环境组合记录：执行人、日期、commit/构建标识、Windows 版本、显示器、分辨率、系统缩放、Qt logical DPI、device pixel ratio、窗口尺寸、启动方式和主题。
- 每个项目保存可追溯记录；适合截图的项目记录截图文件名或证据链接，不适合截图的项目记录操作步骤和观察文字。
- 结果只允许填写 `PASS`、`FAIL`、`BLOCKED` 或 `N/A（附批准理由）`。任何 `FAIL/BLOCKED` 必须记录复现步骤、期望、实际、日志位置和责任阶段。
- 未实际执行的单元保持 `未执行 / 留待 Stage 15-G`，不得根据自动化测试、代码阅读或其他设备结果推断通过。
- 目标软件粘贴、Windows 10、课堂设备、触控和多显示器结论不得从当前开发机外推。
